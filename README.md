# ☗ Web将棋 (Shogi - Japanese Chess)

ブラウザで手軽かつ本格的に遊べる、単一HTMLファイル構成の将棋Webアプリケーションです。  
パブリックドメインの伝統的な将棋ルールに完全準拠し、外部画像や市販音源に依存しないクリーンな設計で作られています。

---

## 🌟 主な機能 (Features)

### 1. 2つの対局モード
- **vs AI 対戦:** Minimax探索・評価関数を備えた3段階の難易度（初級・中級・上級）から選択可能
- **2人対局 (パス＆プレイ):** 1台のPCやスマートフォンで先手・後手を交互に操作して対戦可能（棋譜の再現や研究にも最適）

### 2. 本格的な将棋ルールの完全実装
- **全駒の正規の利き:** 飛車・角行・香車の走り（障害物手前停止）、竜・馬のボーナス移動、金・銀・桂・歩・玉の動き
- **敵陣突入での「成り」:** 敵陣3段以内への進入・脱出時の「成り / 不成」選択モーダル（行き所のない駒は自動成り）
- **持ち駒の打込み:** 二歩（にふ）の禁止、行き所のない段への打ち禁止、打ち歩詰めの防止判定
- **王手判定 & 自殺手の禁止:** 王手放置や自ら王手になる着手の禁止チェック

### 3. 充実した対局支援 & 棋譜記録
- **リアルタイム棋譜記録パネル:** 「▲７六歩(7七)」「☖３四歩(3三)」のように指し手・移動元座標を自動記録（最新手への自動スクロール対応）
- **過去局面プレビュー:** 棋譜リストの過去の手数をタップすると、その時点の盤面を瞬時に閲覧可能
- **ワンクリック棋譜コピー:** クリップボードへ現在までの棋譜テキストを一括出力
- **待った (アンドゥ):** ミスした際に直前の局面へ巻き戻し（AI対戦時は2手巻き戻し）
- **盤面反転:** 先手視点・後手視点をいつでもワンタップで切り替え

### 4. 視認性と臨場感にこだわったデザイン
- **本物の黄楊（つげ）漆調デザイン:** CSSグラデーションとドロップシャドウで立体的な駒の輪郭と木目を表現
- **自然な駒の向き:** 相手陣営の駒は五角形の尖った頭と文字が手前を向き、本物の盤面を挟んでいる臨場感を再現
- **Web Audio打音 (Tone.js):** 外部音声ファイルを使わず、ブラウザ内部で駒を打つ音（着手音・駒取り音・成り音）を動的合成

## 🎮 遊び方 (How to Play)

1. **駒の選択:** 自分の駒（または持ち駒台の駒）をタップすると、移動可能なマスが緑色にハイライトされます。
2. **移動・打込み:** ハイライトされたマスをタップすると駒が移動します。
3. **キャンセル / 変更:** 選択中の駒をもう一度タップするか、別の自駒をタップすればスムーズに選択を切り替えられます。
4. **成りの選択:** 敵陣に入った（または敵陣から動いた）際に表示されるダイアログで「成る」または「不成」を選択します。
